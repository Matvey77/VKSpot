# Инструменты разработки

Запускайте из корня репозитория после `npm ci` и `npm run build`.

| Команда                         | Результат                                                                                                |
| ------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `node tools/icons/generate.cjs` | Рендер `resources/icon.svg` в `resources/icon.png`                                                       |
| `node tools/guide/capture.cjs`  | Двадцать снимков настоящего интерфейса и измеренные области элементов в `src/renderer/src/assets/guide/` |

Генераторы запускают Electron с отдельными профилями в `.local/tmp/`.
Руководство использует синтетическую коллекцию; живые подключения не нужны.
Сгенерированную графику проверяйте визуально, сохраняйте её происхождение
и сопровождающие метаданные.

Скрипты, необходимые конечному пользователю, находятся в `resources/scripts/`.
Этот каталог `tools/` в установщик не включается.
