# Инструменты разработки

Внутренние вспомогательные утилиты для разработки и подготовки ассетов приложения. Запускаются из корня репозитория после выполнения `npm ci` и `npm run build`.

| Команда                         | Описание и результат                                                                                                                                      |
| :------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `node tools/icons/generate.cjs` | Растрирование векторного мастер-исходника `resources/icon.svg` в `resources/icon.png` (256×256)                                                           |
| `node tools/guide/capture.cjs`  | Создание 24 снимков настоящего интерфейса (12 сцен в светлой и темной темах) и расчет координат интерактивных маркеров в `src/renderer/src/assets/guide/` |

## Принципы работы генераторов

- Инструменты запускают отдельный экземпляр Electron с изолированными временными профилями в `.local/tmp/`.
- Инструмент захвата кадров руководства использует исключительно изолированную синтетическую тестовую медиатеку и моки ответов; реальные учетные записи пользователей не используются.
- Каталог `tools/` предназначен исключительно для разработки и сборки и не включается в готовый дистрибутив приложения.

## Производительность

После `npm run build` команда `npm run perf` запускает изолированный синтетический профиль на 9000 записей и пишет JSON в `.local/performance/latest.json`. Переменная `VKSPOT_TEST_EXECUTABLE` позволяет проверить готовый exe; `BENCHMARK_OUTPUT` задаёт файл результата. Подробности: [docs/performance-review.md](../docs/performance-review.md).
