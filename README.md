# VKSpot

Автономная локальная библиотека и проверяемый перенос личной медиатеки из VK Музыки в Spotify с сохранением точного порядка, авторских версий и дубликатов.

**Все основные функции работают без покупок, скрытых подписок и внешних облачных серверов. Приложение функционирует на локальном компьютере пользователя.**

---

## Возможности

- **Фоновый поиск через веб-плеер Spotify:** включен по умолчанию и не требует регистрации в Spotify Developer Dashboard или указания Client ID. Приложение самостоятельно подставляет запросы и считывает кандидатов во встроенном представлении Chromium; при необходимости капчи или входа открывает окно прямо в интерфейсе ([docs/browser-search.md](docs/browser-search.md)).
- **Продвинутый алгоритм сопоставления (`src/core/matching.ts`):**
  - Снятие диакритических знаков Unicode (`Beyoncé` ↔ `Beyonce`, `JAŸ-Z` ↔ `JAY-Z`).
  - Фолдинг омоглифов кириллицы и латиницы (`MOT` ↔ `МОТ`, `СМН` ↔ `CMH`).
  - Очистка названий от дублирования приглашенных артистов в скобках `(feat. ...)` и `[with ...]`.
  - Автосопоставление идентичных версий (`Remix`, `Mix`, `Edit`, `2026 Version`, пользовательские теги).
  - Мягкая пунктуация для ремиксов и распознавание ремиксера в составе артистов.
  - Настраиваемый допуск по хронометражу (до 5 секунд по умолчанию) для компенсации тишины и фейдаутов MP3-файлов VK.
  - Автоматический выбор основного студийного релиза при наличии дубликатов (сингл vs альбом) с отсечением live-версий.
  - Поддержка треков с неизвестной длительностью в VK при согласованности кандидатов стриминга.
- **Встроенное предпрослушивание аудио:** плеер VK Music в скрытом окне с полноценным viewport, ожиданием рекламы и подтверждением времени оригинала; превью кандидатов Spotify прямо в инспекторе для проверки спорных версий на слух.
- **Интеллектуальная таблица и инспектор:** виртуализированная таблица TanStack для коллекций любого масштаба (9 000+ записей), быстрые фильтры по статусам, настраиваемый инспектор (параллельное и последовательное размещение, регулировка ширины от 340 до 800px).
- **Управление коллекциями (v0.1.30):** просторные карточки, переименование, изменение порядка, экспорт и синхронизация из VK целиком или по диапазону с сохранением рабочих решений.
- **Экран «Начало»:** интеллектуально определяет фактическое состояние библиотеки и предлагает одно следующее целевое действие.
- **Автопродолжение фонового поиска:** сохранение прогресса в SQLite, возобновление после перезапуска и интеллектуальная обработка платформенных лимитов `Retry-After` Spotify.
- **Производительность (v0.1.31):** точечный обмен изменениями вместо передачи всей медиатеки, стабильные ссылки на неизменённые строки, общий кэш анализа и виртуализация видимого диапазона. На синтетической библиотеке из 9000 записей штатное обновление сократилось со 151,5 до 0,3 мс; подробная методика — в [отчёте](docs/performance-review.md).
- **Смешанный перенос:** перенос каталожных совпадений напрямую в плейлист Spotify плюс подготовка локальных аудиофайлов для редких треков, отсутствующих на стриминге, с сохранением единой сквозной нумерации.
- **Локальное хранение и приватность:** база данных SQLite с WAL-режимом и триггерами защиты от перезаписи оригиналов, шифрование токенов через системный `safeStorage` ОС, без телеметрии и скрытых сетевых запросов.
- **Экспорт и архивация:** сохранение полного архива VKSpot, списков TXT/CSV, M3U8 и сопровождающего плана переноса.
- **Системная панель мониторинга:** отображение статусов сессий VK и Spotify в реальном времени, мониторинг активных задач и прогресса прямо в сайдбаре.

## Быстрый запуск для разработчиков

Приложение собирается под Windows (x64) с помощью `electron-builder`:

```sh
# Установка зависимостей (требуется Node.js 24 LTS)
npm ci

# Запуск в режиме разработки
npm run dev

# Проверка качества кода, типов и тестов
npm run typecheck       # Проверка строгой типизации TypeScript
npm run lint            # Проверка ESLint
npm run format:check    # Проверка форматирования Prettier
npm test                # 100 модульных тестов Vitest
npm run test:e2e        # 57 сквозных тестов Playwright в реальном Electron

# Сборка готового установщика
npm run dist:win        # Создаёт release/<версия>/VKSpot Setup <версия>.exe
```

Пользователю готового приложения Node.js, компиляторы и SDK не требуются. Проект не требует внешнего сервера или отдельной регистрации аккаунта VKSpot.

## Порядок работы пользователя

1. **Импорт библиотеки:** Импортируй готовый файл списка (JSON, CSV, TXT) либо открой **Подключения → VK** и войди в свой аккаунт.
2. **Выгрузка из VK:** Открой вкладку **Моя музыка** в окне VK и нажми **Выгрузить мой список**. Приложение автоматически соберет список аудиозаписей с контролем разрывов прокрутки. Сохрани полный архив библиотеки.
3. **Фоновый поиск:** После сохранения импорта поиск кандидатов в Spotify запускается автоматически (через веб-плеер, Client ID не нужен). Прогресс отображается в таблице и системной панели сайдбара.
4. **Массовое подтверждение:** Нажми **Выделить совпадения** и **Подтвердить выбранные**. Все однозначные совпадения мгновенно привяжутся к целевому назначению Spotify.
5. **Разбор спорных версий:** Нажми строку таблицы или стрелку разбора, чтобы открыть инспектор. Сравнивай треки визуально и на слух через встроенные аудиоплееры VK и Spotify.
   Если поиск не возвращает известный трек, нажми **«Указать трек Spotify»**, вставь ссылку или URI и проверь описание перед подтверждением. Подключение Spotify API для ручной привязки не требуется.
6. **Привязка локальных файлов:** Для треков, отсутствующих в каталоге Spotify, привяжи имеющиеся на диске аудиофайлы или нажми «Нужен файл».
7. **Формирование плана и перенос:** Проверь итоговый план переноса. Каталожные треки будут добавлены в новый плейлист Spotify через официальный API.
8. **Сверка смешанного порядка:** Скопируй подготовленные локальные файлы в папку локальных файлов Spotify и запусти **Сверить смешанный порядок** в задании для гарантии 100% совпадения исходной последовательности.

Подробное руководство по разбору: [docs/matching-workflow.md](docs/matching-workflow.md).

## Подключение Spotify API (для создания плейлиста)

Поиск через веб-плеер Spotify не требует этого подключения. Для непосредственного создания плейлиста в аккаунте используется официальный Spotify Web API:

1. Открой **Подключения → Spotify API — подключение для переноса**.
2. Создай личное приложение на портале [Spotify for Developers](https://developer.spotify.com/dashboard).
3. Добавь точный Redirect URI в настройках приложения:
   ```text
   http://127.0.0.1:43823/callback
   ```
4. Укажи Client ID в поле настроек VKSpot, сохрани настройки и нажми **Войти в Spotify**. Client Secret указывать не требуется (авторизация по безопасному протоколу OAuth 2.0 PKCE).
5. Если в вашем регионе Spotify сообщает об ограничении доступа (`Spotify is unavailable in this country`), укажите HTTP или SOCKS5 адрес своего локального VPN/прокси (например, `http://127.0.0.1:2080`) в поле **Прокси Spotify**.

## Форматы импорта

- **JSON:** Массив объектов либо объект с полем `{ "tracks": [...] }`:
  ```json
  [
    {
      "id": "123_456",
      "artist": "Исполнитель",
      "title": "Название (Remix)",
      "duration": 185,
      "availability": "available"
    }
  ]
  ```
- **CSV:** Поддерживаются разделители `,`, `;`, `\t` и заголовки `artist,title,duration` (или `Исполнитель,Название,Длительность`).
- **TXT:** Одна запись на строку в формате `Исполнитель - Название` либо просто название трека.
- **Полный архив VKSpot (`.json`):** Фирменный формат полного сохранения метаданных, контрольных сумм и истории правок.

## Реальные технические границы системы

- **Приватность учетных записей:** VKSpot принципиально не считывает, не запрашивает и не сохраняет пароли пользователей от VK и Spotify. Любая авторизация выполняется на защищенных официальных страницах сервисов.
- **Локальные файлы в Spotify:** Официальный Spotify Web API не предоставляет технической возможности загружать локальные аудиофайлы в облако Spotify. Добавление локальных файлов производится через стандартную функцию десктопного клиента Spotify («Локальные файлы»), после чего VKSpot проверяет и выстраивает правильный смешанный порядок.
- **Предпрослушивание VK:** Встроенный плеер VK воспроизводит аудиозаписи непосредственно из потоков VK через российские CDN. Загрузка треков на диск в формате MP3 не является задачей приложения — приложение готовит и каталогизирует уже имеющиеся у пользователя файлы.
- **Честность лимитов API:** Скорость сопоставления зависит от платформенных ограничений Spotify. При превышении квоты приложение соблюдает паузу `Retry-After` и автоматически продолжает поиск после кулдауна.

## Хранение данных и безопасность

- Локальная база данных `collection.db` (SQLite с журналом WAL) расположена в системной директории данных ОС (отображается в разделе «Настройки»).
- Токены доступа Spotify сохраняются в зашифрованном файле `spotify.enc` с использованием системного хранилища операционной системы (`Electron safeStorage`).
- Сессии браузера VK изолированы в профиле `persist:vkspot-vk`; сессия очищается по нажатию кнопки «Очистить подключение».
- Приложение не содержит аналитических трекеров, телеметрии и не передает данные на сторонние серверы ([SECURITY.md](SECURITY.md)).
