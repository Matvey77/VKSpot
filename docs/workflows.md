# Рабочие процессы

## Импорт и выгрузка VK

Можно импортировать JSON, CSV или TXT либо открыть VK в приложении и выгрузить «Мою музыку». Интеграция читает видимый DOM во встроенной изолированной сессии, не перехватывает пароль/cookies/токены и не вызывает закрытые API. VK-адаптер поддерживает современную и классическую разметку, следует внутренней ссылке на «Мою музыку», собирает перекрывающиеся видимые фрагменты виртуального списка и сохраняет каждый повтор отдельно.

Полнота `verified-count` подтверждается только при совпадении ожидаемого (указанного пользователем или `aria-setsize`) количества и полей. Достижение конца без точного счётчика — `unverified`, требуется сверить первые и последние записи. Пустой результат без названий и исполнителей отвергается. Страница VK может меняться; если разметка или сеть мешает выгрузке, результат не следует считать полным. Предпрослушивание оригинала проходит в скрытом полноразмерном окне: VK может сначала показать рекламу; статус воспроизведения требует подтверждения аудио, а не одной иконки.

## Поиск и решения

После импорта поиск по умолчанию выполняется во встроенном веб-плеере Spotify; Client ID и Developer Dashboard для поиска не нужны. Профиль отдельный, чтение происходит по отображённой выдаче DOM. Вход/капча требуют пользователя. Spotify может менять сайт, локали и DOM, а доступность зависит от сети и региона. Поиск через официальный API доступен как альтернативный режим и может упереться в платформенную квоту.

Результат поиска и назначение — разные состояния. «Ничего не найдено» описывает последнюю пустую выдачу, но не доказывает отсутствие версии в каталоге. Сопоставление учитывает Unicode, диакритику, омоглифы, транслитерацию, гостевых исполнителей, продюсерские суффиксы и пунктуацию. Одинаковая версия при совпадении остальных критериев получает статус «Совпадают данные»; подтверждает назначение пользователь. Спорная версия требует отдельной проверки. Допуск длительности — 5 секунд по умолчанию, 2 секунды в строгом режиме. Без исходной длительности совпадение допускается при точных метаданных и согласованных длительностях кандидатов. Правила — `src/core/matching.ts`, граничные случаи — `tests/unit/matching.test.ts`.

Однозначные результаты можно выделить и подтвердить массово. В остальных случаях инспектор сравнивает оригинал и кандидатов визуально и на слух. Если известная ссылка не найдена поиском, можно вручную указать Spotify track URI/ссылку и проверить метаданные. Решения относятся к рабочей копии и отменяются.

## Очереди и перенос

Поиск и перенос сохраняют курсор в SQLite и доступны для продолжения после перезапуска. Пауза пользователя не снимается автоматически; `Retry-After` браузерного поиска и API соблюдается с видимым таймером и возможностью автопродолжения поиска после срока. Не обходить лимиты платформы.

Каталожные Spotify URI добавляются в плейлист через официальный Web API (OAuth PKCE, Client ID, без Client Secret). API не загружает локальные аудиофайлы. Для отсутствующих треков VKSpot подготавливает копии уже имеющихся файлов без перекодирования и нумерует по исходному плану. Пользователь добавляет папку как Local Files в настольном Spotify; затем VKSpot сверяет смешанный порядок. Файлы должны быть доступны на устройстве, где играет Spotify.

Для Spotify и VK предусмотрены независимые настройки HTTP/SOCKS5-прокси. Пустой прокси Spotify использует системную сеть; VK по умолчанию работает напрямую.

Экспорт из параметров коллекции: полный архив VKSpot JSON, исходный VK JSON, CSV, план JSON и M3U8. Архив не включает аудиофайлы. Импорт TXT — `Исполнитель - Название` на строку; CSV — колонки исполнителя/названия/длительности; JSON — массив треков, объект `tracks` или архив VKSpot.

Прямые ссылки на песни или предпрослушивание могут перестать работать из-за изменений платформ. Ограничения и ошибки показываются пользователю, а не трактуются как подтверждённый матч.

## Подключение Spotify API

Нужно для создания плейлиста и альтернативного поиска через API. Поиск через встроенную страницу подключается отдельно и не требует Client ID.

1. Открой [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) и создай личное приложение с Web API.
2. Укажи Redirect URI: `http://127.0.0.1:43823/callback`.
3. Скопируй **Client ID** в VKSpot → «Подключения» → Spotify и сохрани настройки. Client Secret не нужен.
4. Нажми «Войти в Spotify» и подтверди доступ в браузере.

По [правилам Development Mode](https://developer.spotify.com/documentation/web-api/concepts/quota-modes), владельцу API-приложения нужен Premium; допускается до пяти авторизованных пользователей из списка разрешённых. Каждый пользователь VKSpot настраивает своё приложение; общего Client ID проект не предоставляет. Квоты могут приостановить поиск или перенос — статус виден в заданиях.
