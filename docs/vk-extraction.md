# Выгрузка списка VK

Адаптер собирает описания записей в отдельном окне VK. Он не скачивает аудио,
не отправляет запросы к закрытым API и не выгружает cookies, токены, хеши
доступа или адреса воспроизведения.

## Чтение записей

- Современная разметка: `data-audio-id` и поля `MusicTrackRow_Title`,
  `MusicTrackRow_Authors`, `MusicTrackRow_Duration`.
- Несколько исполнителей читаются вместе с разделителями общего поля.
- Старая разметка: `audio_row`, `audio_item`, `data-full-id`, `data-audio`.
- Из JSON `data-audio` выбираются только ID, название, исполнитель,
  длительность и явные признаки недоступности. Сам JSON не экспортируется.
- Массивы и объекты метаданных поддерживаются отдельно; HTML-сущности
  в названиях декодируются без выполнения содержимого.
- Обозначения версий и видимые подзаголовки сохраняются. Переименования,
  определения версии на слух и удаления повторов нет.

Селекторы современной страницы и отдельные ссылки исполнителей проверены
через сохранённую локальную сессию владельца. `/audio` открывает «Главную»;
перед сбором приложение следует собственной ссылке VK на вкладку «Моя музыка».
Ссылка проверяется по протоколу, домену и пути. Данные аккаунта при этом
не редактируются. При отсутствии такой вкладки остаётся ручной переход.

Источники для сопоставления форматов, без заимствования реализации:
[публичный код VK Music List Copier](https://greasyfork.org/id/scripts/587484-vk-music-list-copier/code)
и [парсер python273/vk_api](https://github.com/python273/vk_api/blob/master/vk_api/audio.py).
Актуальная разметка живой страницы имеет приоритет перед этими примерами.

## Прокрутка и порядок

1. Возврат к началу подходящей области прокрутки.
2. Чтение строк в порядке расположения, затем прокрутка на часть высоты окна.
3. Сопоставление пересекающихся последовательностей по ID, позициям ARIA
   и координатам строк. Каждое вхождение сохраняется отдельно.
4. При разрыве — возврат к предыдущей позиции, ожидание и меньший шаг.
   Несвязанный фрагмент не добавляется молча.
5. Внизу — ожидание следующей порции VK до 18 секунд без новых записей.
   Конец загруженной страницы сам по себе не доказывает полноту библиотеки.

Проход продолжается, пока появляются новые записи: общего ограничения в
20 минут больше нет. Адаптер останавливается после двух минут без новых
записей либо 12 000 итераций. Главный процесс отдельно прерывает зависшее
чтение после трёх минут без прироста счётчика. Срабатывание ограничения,
смена страницы, разрыв или остановка пользователем оставляют результат
непроверенным. Приложение показывает число собранных записей и позволяет
остановить сбор. Прочитанные записи можно затем явно сохранить как
непроверенный список; автоматического сохранения и возобновления после
закрытия приложения нет.

Скрипт выполняется в отдельном JavaScript-мире Electron. Кеш чтения строк
ускоряет повторные проходы, но проверяет изменившийся текст и атрибуты, чтобы
учитывать переиспользование элементов виртуализированной страницы.

## Подтверждение результата

Можно указать точное ожидаемое число записей; если оно неизвестно, поле
следует оставить пустым. Приблизительное число не ускоряет и не продлевает
сбор. Если VK предоставляет
`aria-setsize`, оно также учитывается. Статус `verified-count` означает только
совпадение количества при нормальном завершении, отсутствии непрочитанных
полей и противоречащих счётчиков. Он не подтверждает доступность аудио,
правильность музыкальной версии или перенос в Spotify.

Если все названия и исполнители пусты, результат отклоняется. Отдельные
непрочитанные поля сохраняются вместе с предупреждением. Непроверенный
результат требует отдельной отметки перед сохранением. В предварительном
просмотре видны первые и последние записи с исходными позициями.

## Проверки

`tests/e2e/vk-export.spec.ts` запускает настоящий Electron и подменяет ответы
VK синтетическими HTML-страницами в отдельном профиле. Проверяются 8307
виртуализированных вхождений с одинаковым ID, недоступные записи, несколько
исполнителей, вложенная прокрутка, отсутствие ARIA, дозагрузка после 398
строк, обе формы JSON, разрывы последовательности, отмена, пустые названия
и переход с главной страницы к личной библиотеке. Отдельно проверяются
продолжение активного сбора дольше 20 минут по тестовым часам и остановка
прокрутки без новых записей.

Ускоряется только время ожидания адаптера. Геометрия, отрисовка, прокрутка,
включая ожидание настоящих кадров Chromium перед следующим чтением,
изоляция Electron, IPC и интерфейс подтверждения остаются настоящими.
Тесты не подключают Spotify и не используют реальную коллекцию. Они задают
`VKSPOT_BACKGROUND_TEST=1` вместе с отдельным `VKSPOT_DATA_DIR`: окна прозрачны,
не получают фокус, не перехватывают мышь и скрыты с панели задач. Нативная
поверхность Chromium сохраняется для настоящей отрисовки и прокрутки.
Обычный запуск приложения эти параметры не включает.
