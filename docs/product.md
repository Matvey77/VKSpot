# Продукт VKSpot

Автономное десктопное приложение для локального архивирования и проверяемого переноса личной медиатеки из VK Музыки в Spotify с сохранением точного порядка, авторских версий и дубликатов.

## 1. Платформа и стек

- **Среда выполнения:** Electron 44 (Chromium + Node.js 24 LTS). Целевая ОС — Windows 10/11 (x64).
- **Хранилище:** Встроенный модуль `node:sqlite` с WAL-журналированием и триггерами защиты от перезаписи (`source_immutable`). Индексированный кэш коллекций и подготовленные SQL-запросы.
- **Интерфейс:** React 19, TypeScript (строгий режим), Vite, TanStack Virtual для работы со списками от 10 000+ записей с виртуализацией видимых строк, Lucide Icons.
- **Безопасность:** Шифрование учетных данных через `Electron safeStorage`, изолированные миры выполнения (`isolatedWorld`), строгая типизация и валидация IPC-контрактов через Zod.

## 2. Целевая аудитория и задача

Пользователи с большими личными коллекциями аудиозаписей в VK (от сотен до десятков тысяч треков), стремящиеся перенести медиатеку в Spotify без потерь:

- сохраняя порядок воспроизведения;
- сохраняя намеренные повторы записей;
- исключая слепую подмену редких ремиксов, мэшапов, каверов и концертных версий на стандартные студийные треки;
- решая проблему треков, отсутствующих в стриминге, через подготовку локальных файлов.

## 3. Ключевые принципы

1. **Неизменяемость оригинала:** Исходные данные VK неприкосновенны. Любые пользовательские корректировки сохраняются в рабочей копии, обратимы и протоколируются с возможностью отмены (`Undo`).
2. **Идентичность каждого вхождения:** Каждая строка коллекции обладает уникальным UUID и порядковым номером. Одинаковые треки не схлопываются.
3. **Прозрачность неопределенности:** Спорные совпадения, заблокированные композиции и варианты без точных соответствий четко выделяются и требуют осознанного выбора пользователя.
4. **Отказоустойчивость и локальность:** Вся база данных и состояние очередей хранятся локально в SQLite. Приложение устойчиво к прерываниям и перезапускам.
5. **Честность платформенных лимитов:** Ограничения внешних сервисов (HTTP 429, `Retry-After`) отображаются с точным таймером обратного отсчета без ложных обещаний мгновенной работы.
6. **Полная бесплатность и приватность:** Приложение не использует внешних платных API, облачных серверов или телеметрии. Учетные данные пользователя не перехватываются.

## 4. Ключевые возможности

- **Фоновый поиск через веб-плеер Spotify:** Поиск кандидатов «из коробки» во встроенном изолированном представлении Chromium без необходимости создавать приложение в Spotify Developer Dashboard или указывать Client ID.
- **Интеллектуальный механизм сопоставления:** Снятие диакритики Unicode, нормализация омоглифов кириллицы/латиницы, очистка приглашенных артистов `(feat. / with)`, распознавание идентичных версий и безопасный допуск по длительности до 5 секунд.
- **Встроенное предпрослушивание:** Прямое воспроизведение аудиозаписей VK Music (через изолированный оффскрин-плеер с прямым CDN) и превью Spotify непосредственно в инспекторе.
- **Инспектор коллекции:** Двухрежимное отображение (параллельное и последовательное) с гибкой регулировкой ширины и сохранением пользовательских параметров.
- **Модульная организация рабочего пространства:** Выделенные разделы «Начало», «Коллекция», «Подключения», «Задачи», «Экспорт» и «Настройки» с сохранением состояния фильтров, выделения и несохраненных черновиков при переключении между вкладками.
- **Смешанный перенос:** Формирование каталожного плейлиста в Spotify и подготовка локальных аудиофайлов с корректной нумерацией для редких треков.
