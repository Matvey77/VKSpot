# Продукт VKSpot

## Платформа

Десктопное приложение на веб-технологиях (Electron, React, TypeScript). Основная целевая ОС — Windows (x64).

## Стек

- **Ядро и бекенд:** Electron (Chromium + Node.js 24 LTS), встроенный модуль `node:sqlite` с WAL-журналированием.
- **Интерфейс:** React 19, TypeScript (строгий режим), TanStack Table и TanStack Virtual для виртуализации больших списков, Lucide Icons.
- **Безопасность:** шифрование токенов через системный `safeStorage`, изоляция контекстов и миров выполнения (isolated world), строгие Zod-схемы валидации IPC.

## Пользователи

Пользователи с большими личными коллекциями аудиозаписей в VK (от сотен до десятков тысяч треков), желающие перенести музыку в Spotify без потери порядка, дубликатов, редких ремиксов и пользовательских загрузок.

## Цель продукта

Сохранить каждую исходную запись коллекции VK в неизменяемом виде, сформировать рабочий список для сопоставления и создать проверяемый смешанный плейлист Spotify (каталожные треки + подготовленные локальные файлы для отсутствующих записей).

## Принципы продукта

1. **Неизменяемость оригинала:** сырые записи VK неприкосновенны; любые пользовательские правки и решения обратимы и имеют историю отмены.
2. **Сохранение идентичности и порядка:** каждая запись имеет уникальный идентификатор и порядковый номер. Повторы треков не схлопываются молча.
3. **Прозрачность неопределённости:** спорные версии, отсутствие кандидатов и заблокированные треки явно видны в интерфейсе и требуют осознанного решения.
4. **Устойчивость к сбоям:** весь прогресс и состояние сохраняются локально в SQLite; приложение готово к закрытию и перезапуску на любом этапе.
5. **Честность ограничений:** лимиты внешних API (например, `Retry-After` от Spotify) отображаются с точным таймером ожидания без ложных обещаний мгновенной работы.
6. **Бесплатность и приватность:** базовые функции не требуют платных подписок или внешних серверов; пароли не перехватываются, данные хранятся только на компьютере пользователя.

## Ключевые возможности

- **Фоновый поиск через страницу Spotify:** работает по умолчанию без необходимости создавать приложение Spotify Developer и получать Client ID.
- **Интеллектуальное сопоставление:** снятие диакритики, омоглифы кириллицы/латиницы, очистка гостей (`feat`/`with`), автосопоставление идентичных версий, умный выбор между синглами и альбомами.
- **Аудиоплееры предпрослушивания:** прямое прослушивание треков VK Music и кандидатов Spotify в инспекторе для проверки версий на слух.
- **Инспектор таблицы:** параллельный и последовательный режимы отображения с регулировкой ширины.
- **Автопродолжение очереди:** возобновление работы после таймаутов Spotify с сохранением приоритета ручной паузы.
- **Высокая производительность:** многоуровневый in-memory кэш и сигнатурная мемоизация для плавной работы на 9 000+ треках.
