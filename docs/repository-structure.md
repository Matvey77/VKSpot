# Структура репозитория

В корне остаются README, лицензия, правила участия и безопасности, DESIGN.md,
манифесты зависимостей и стандартные конфигурации инструментов. Требования,
описание продукта и справочные материалы находятся в `docs/`.

## Исходники

| Каталог         | Назначение                                                          |
| --------------- | ------------------------------------------------------------------- |
| `src/core/`     | Форматы импорта и экспорта, исходные записи, план и сверка порядка  |
| `src/shared/`   | Общие типы, схемы Zod и контракт разрешённых команд                 |
| `src/main/`     | Главный процесс Electron: SQLite, Spotify, задания, файлы и окно VK |
| `src/preload/`  | Изолированный мост между главным процессом и интерфейсом            |
| `src/renderer/` | HTML-точка входа, React-компоненты, стили и графика интерфейса      |
| `resources/`    | Иконка приложения и скрипты, включаемые в установщик                |
| `tools/`        | Инструменты разработчика, которые не поставляются пользователю      |
| `tests/unit/`   | Проверки логики и хранения                                          |
| `tests/e2e/`    | Проверки настоящего Electron с отдельными тестовыми профилями       |

`src/renderer/src/assets/brands/` содержит оригинальные SVG-знаки сервисов и
знак VKSpot. `assets/guide/` содержит двадцать четыре снимка настоящего интерфейса,
измеренные области элементов и описание происхождения. Это часть приложения,
а не временные результаты тестов. Сохраняйте сопровождающие метаданные.

`resources/scripts/vk-export.js` — пробный адаптер VK.
`resources/scripts/windows/` — диагностический помощник Windows.
В режиме разработки приложение читает скрипты из этого каталога; в готовой
сборке они находятся в `resources/scripts/` рядом с `app.asar`.

## Локальные результаты

Эти каталоги исключены из Git и форматирования:

| Каталог                | Содержимое                                                 |
| ---------------------- | ---------------------------------------------------------- |
| `node_modules/`        | Зависимости, восстанавливаемые командой `npm ci`           |
| `out/`                 | Результат `npm run build`                                  |
| `release/<версия>/`    | Установщик, блок-карта и распакованная сборка одной версии |
| `.local/evidence/e2e/` | Снимки интерфейса, создаваемые e2e-проверками              |
| `.local/test-results/` | Результаты и диагностика Playwright                        |
| `.local/tmp/`          | Временные профили инструментов разработки                  |
| `.local/archive/`      | Сохранённые старые черновики и служебные материалы         |

Сборщик автоматически выбирает папку `release/<версия>/` из `package.json`.
Исходники не импортируют файлы из локальных результатов. Повторяемые задачи
оформляйте в `tools/`, разовые черновики держите в `.local/`.

Тесты создают коллекции в изолированных временных профилях. Генераторы графики
удаляют собственные профили после нормального завершения. При ошибке запуска
профиль может остаться в `.local/tmp/` для диагностики.
Настоящая пользовательская база хранится в системной папке приложения,
показанной в настройках, и к рабочим результатам проекта не относится.

### Ключевые модули

- `src/main/store.ts` — транзакционное хранилище SQLite (WAL) с in-memory кэшированием коллекций и быстрым чтением.
- `src/main/jobs.ts` — менеджер фоновых очередей, троттлинг IPC-уведомлений и сохранение прогресса.
- `src/main/spotify-browser.ts` — изолированное представление для фонового поиска через `open.spotify.com`.
- `src/main/vk-audio.ts` — фоновый плеер аудиозаписей VK Music без прокси для предпрослушивания.
- `src/main/vk-status.ts` — пассивный классификатор статуса страницы VK по DOM-сигналам.
- `src/renderer/src/`:
  - `StartPage.tsx` — контекстный главный экран (следующий шаг по состоянию коллекции).
  - `CollectionTable.tsx` — виртуализированная таблица записей и боковой инспектор с плеерами.
  - `ReviewWorkspace.tsx` — пошаговый разбор версий и неточных совпадений.
  - `SettingsForms.tsx` — параметры поиска (радио-карточки), правила сопоставления, сетевые прокси.
  - `SidebarStatus.tsx` — монитор подключений VK/Spotify и прогресса активного задания.
  - `SpotifyPanel.tsx` — интерактивное всплывающее окно веб-плеера Spotify при капче или логине.
  - `Welcome.tsx` — подробная иллюстрированная инструкция с реальными кадрами интерфейса.
