# Структура репозитория и архитектура компонентов

Документ описывает организацию каталогов проекта VKSpot, назначение исходных модулей и правила размещения файлов.

---

## 1. Общая структура каталогов

```text
VKSpot/
├── .github/          # Сценарии автоматической сборки и тестирования GitHub Actions
├── .impeccable/      # Токены и спецификации дизайн-системы (Impeccable)
├── docs/             # Архитектурная документация, спецификации и руководства
├── resources/        # Статические ресурсы (иконки, поставляемые служебные скрипты)
├── src/              # Исходный код приложения
│   ├── core/         # Чистая бизнес-логика (не зависит от Electron и React)
│   ├── shared/       # Общие типы данных, Zod-схемы и контракты IPC
│   ├── main/         # Главный процесс Electron (СУБД SQLite, сервисы, IPC)
│   ├── preload/      # Безопасный изолированный контекстный мост (contextBridge)
│   └── renderer/     # Пользовательский интерфейс (React 19, стили, ассеты)
├── tests/            # Наборы тестов (Vitest для unit-тестов, Playwright для Electron E2E)
├── tools/            # Инструменты разработчика (снятие кадров руководства, генераторы иконок)
├── CONTRIBUTING.md   # Руководство для участников разработки
├── DESIGN.md         # Нормативная спецификация дизайн-системы и токены
├── LICENSE           # Текст лицензии (MIT)
├── README.md         # Главная точка входа и руководство пользователя
├── SECURITY.md       # Политика безопасности и модель угроз
└── package.json      # Зависимости, скрипты сборки и манифест electron-builder
```

## 2. Исходные модули (`src/`)

### `src/core/` — Чистая бизнес-логика

- `collection.ts` — Создание коллекций, вычисление контрольных сумм SHA-256 (`sourceHash`), валидация целостности, парсеры импорта (JSON, CSV, TXT), генераторы экспорта (VKSpot Archive, Plan, M3U8, CSV), сверка смешанного порядка (`reconcilePrefix`, `mixedOrder`).
- `matching.ts` — Алгоритм сопоставления (`metadataMatch`), нормализация Unicode (NFD/NFKC), фолдинг омоглифов, дедупликация `feat./with`, обработка идентичных версий и расчет принадлежности к группам разбора (`reviewGroup`).
- `vk-import.ts` — Zod-схемы валидации данных экспорта VK и преобразование сырых структур в `ImportPreview`.

### `src/shared/` — Общие контракты

- `model.ts` — Центральные схемы Zod и типы TypeScript: `TrackRow`, `Collection`, `Working`, `RawTrack`, `SpotifyTrack`, `LocalFile`, `Settings`, `Job`, `Bridge`, `AppState`.
- `job-status.ts` — Вспомогательные функции расчета состояний задач, таймеров `Retry-After`, форматирования сообщений об ограничениях квот и логика автопоиска.

### `src/main/` — Главный процесс Electron

- `index.ts` — Инициализация главного окна (`BrowserWindow`), регистрация строгих IPC-обработчиков с Zod-валидацией, управление жизненным циклом приложения.
- `network.ts` — Изолированное конфигурирование сессионных сетевых прокси (VK и Spotify) и утилита проверки задержки соединения (`testProxy`).
- `files.ts` — Системные файловые диалоги Electron, упаковка архивов локальной музыки, верификация контрольных сумм SHA-256 и запуск PowerShell-хелпера интеграции со Spotify.
- `vk-session.ts` — Менеджер изолированного браузерного окна VK (`VKSessionManager`), инъекция DOM-скрейпера (`vk-export.js`), отслеживание навигации и безопасная остановка сбора.
- `store.ts` — Хранилище на базе встроенного `node:sqlite` с WAL-режимом, триггером `source_immutable`, историей изменений (`Undo`), in-memory кэшированием коллекций со временем отклика 0.001 мс и кэшем поисковых ответов.
- `jobs.ts` — Менеджер фоновых очередей (`search`, `transfer`), контроль курсора, троттлинг IPC-событий (1200 мс), автовозобновление после снятия лимитов платформы.
- `spotify-browser.ts` — Изолированное окружение Chromium для фонового поиска через `open.spotify.com`, парсинг DOM, санитизация URL, мультиязычное распознавание пустой выдачи и обработка капчи.
- `spotify.ts` — Клиент официального Spotify Web API: авторизация OAuth 2.0 PKCE через системный браузер, шифрование токенов системным `safeStorage`, создание плейлистов и пакетное добавление треков.
- `vk-audio.ts` — Изолированный оффскрин-плеер аудиозаписей VK Music с десктопным разрешением (1280x800) и прямой маршрутизацией через российские CDN без прокси.
- `vk-status.ts` — Пассивный классификатор статуса страницы VK по видимым DOM-сигналам без чтения паролей и cookies.

### `src/preload/` — Мост изоляции

- `index.ts` — Безопасное предоставление строго типизированного объекта `window.vkspot` через `contextBridge.exposeInMainWorld`.

### `src/renderer/src/` — Пользовательский интерфейс (React 19)

- `App.tsx` — Корневой компонент: управление глобальным состоянием, навигацией между вкладками, централизованной обработкой черновиков, модальными окнами и системными диалогами.
- `CollectionsOverview.tsx` — Список коллекций: открытие, переименование, изменение порядка, экспорт, удаление и запуск синхронизации.
- `RepairDialog.tsx` — Синхронизация коллекции из VK или файла с выбором всей библиотеки, первых N записей или диапазона.
- `LibraryView.tsx` — Вкладка «Коллекция»: панель управления (поиск, фильтры, быстрые действия, массовый выбор треков), виртуализированная таблица и боковой инспектор с поддержкой изменения ширины (resize).
- `ConnectionsView.tsx` — Вкладка «Подключения»: управление сессией VK (браузерный сбор аудиотеки), интеграция Spotify (OAuth/веб-сессия) и каталоги локальных аудиофайлов.
- `JobsView.tsx` — Вкладка «Задачи»: мониторинг активных и завершенных фоновых процессов, управление паузой/возобновлением, восстановление плейлистов и сверка смешанного порядка.
- `ArchiveView.tsx` — Вкладка «Экспорт»: выгрузка коллекции в 5 форматах (VKSpot Archive, Plan, M3U8, CSV, Raw JSON) с расчетом контрольных сумм SHA-256.
- `SettingsView.tsx` — Вкладка «Настройки»: конфигурация провайдеров сопоставления, сетевых прокси, тема оформления и путь к рабочей базе данных SQLite.
- `StartPage.tsx` — Интеллектуальный экран «Начало», определяющий текущее состояние библиотеки и предлагающий одно следующее целевое действие.
- `CollectionTable.tsx` — Виртуализированная таблица TanStack (`TrackTable`) и двухрежимный боковой инспектор (`Inspector`) с плеерами предпрослушивания.
- `SettingsForms.tsx` — Формы настроек: сегментированные радио-карточки выбора провайдера поиска, правила сопоставления, сетевые прокси с проверкой пинга и восстановление плейлистов.
- `SidebarStatus.tsx` — Системная панель мониторинга в сайдбаре: статусы подключений VK и Spotify, шкала прогресса и курсор активного задания.
- `SpotifyPanel.tsx` — Интерактивное окно встроенного браузера Spotify при необходимости прохождения капчи или ручной авторизации.
- `ImportDialog.tsx` — Модальное окно предварительного просмотра импорта: сверка метаданных, предупреждения о контрольных суммах и подтверждение загрузки.
- `TransferDialog.tsx` — Модальное окно подтверждения миграции: сводка по трекам (Spotify/локальные/пропущенные), выбор целевого плейлиста и запуск трансфера.
- `CompletenessNotice.tsx` — Информационный баннер неполноты выгрузки VK Music с рекомендациями по повторному сбору.
- `IconButton.tsx` — Доступный переиспользуемый компонент кнопки-иконки с тултипом Radix UI.
- `ExplainedButton.tsx` — Кнопки действий с всплывающими подсказками о причинах блокировки (кулдаун, пауза, отсутствие подключения).
- `SearchControls.tsx` — Панель фильтров по группам разбора (`ReviewGroup`), текстовый поиск и быстрое выделение совпадений.
- `TabList.tsx` — Навигационная панель переключения вкладок с поддержкой стандарта доступности WAI-ARIA Tabs.
- `useRetryClock.ts` — Пользовательский хук синхронизации таймера обратного отсчета кулдауна платформ (`Retry-After`).
- `GuideAssets.ts` — Структура данных и манифест графических ассетов интерактивного руководства.
- `Welcome.tsx` — Интерактивное руководство по работе с приложением с реальными скриншотами интерфейса.
- `BrandIcons.tsx` — Векторные SVG-знаки VK, Spotify и фирменный знак VKSpot с сохранением оригинальных пропорций.
- `main.tsx` — Точка входа рендерера React 19 (монтирование корневого компонента в DOM).
- `style.css` — Единая таблица стилей с поддержкой светлой и темной тем на базе токенов дизайн-системы.

## 3. Каталоги данных и исключения

| Каталог             | Назначение                                                  | Статус в Git  |
| :------------------ | :---------------------------------------------------------- | :-----------: |
| `node_modules/`     | Внешние зависимости приложения                              |   Исключен    |
| `out/`              | Скомпилированные бандлы Vite / electron-vite                |   Исключен    |
| `release/<версия>/` | Собранные установщики NSIS и распакованные сборки           |   Исключен    |
| `.local/`           | Локальные тестовые профили, временные дампы и скриншоты E2E |   Исключен    |
| `resources/`        | Иконки и скрипты, упаковываемые в дистрибутив               | В репозитории |
| `tools/`            | Инструменты разработки (не включаются в установщик)         | В репозитории |
| `docs/`             | Полный комплект архитектурной и технической документации    | В репозитории |

Пользовательские данные (настоящая база данных `collection.db`, токены `spotify.enc` и журнал) хранятся в стандартной системной папке данных ОС (`%APPDATA%/VKSpot` на Windows), отображаемой в разделе «Настройки», и никогда не попадают в репозиторий.
