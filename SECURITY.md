# Безопасность и политика приватности VKSpot

Безопасность пользовательских данных и локальная изоляция являются фундаментальными приоритетами архитектуры VKSpot.

---

## 1. Архитектурные принципы безопасности

1. **Изоляция удаленного веб-контента:**
   - Веб-страницы VK и Spotify загружаются в строго изолированных представлениях `WebContentsView` без доступа к Node.js API (`nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`, `backgroundThrottling: false`).
2. **Изолированные миры выполнения (`isolatedWorld`):**
   - Все сценарии автоматизированного сбора (выгрузка VK, чтение результатов поиска Spotify) выполняются в изолированных контекстах выполнения JavaScript.
   - Скрипты имеют доступ только к текстовому содержимому отрисованного DOM-дерева и не могут считывать внутренние переменные сессий, токены или данные форм.
3. **Строгий и типизированный IPC-контракт:**
   - Окно интерфейса взаимодействует с бэкендом исключительно через безопасный мост `contextBridge` (`src/preload/index.ts`).
   - Каждый входящий IPC-запрос проходит строгую валидацию схем Zod (`src/shared/model.ts`).
   - Обработчики IPC проверяют отправителя на соответствие главному фрейму (`senderFrame === mainFrame`).
4. **Безопасная авторизация OAuth 2.0 PKCE:**
   - Для работы со Spotify Web API используется официальный протокол авторизации Proof Key for Code Exchange (PKCE).
   - Генерация криптографически стойкого `code_verifier`, вычисление `code_challenge` (SHA-256) и временного `state` производятся локально.
   - Локальный HTTP-сервер для получения callback открывается исключительно на интерфейсе `127.0.0.1` на фиксированном локальном порту `43823`, указанном в Redirect URI и закрывается сразу после обмена кода на токен.
5. **Аппаратное и системное шифрование токенов:**
   - Полученные токены доступа Spotify шифруются системным хранилищем операционной системы (`Electron safeStorage`, использующим Windows DPAPI).
   - При недоступности системного хранилища токены доступа принципиально не сохраняются на диск в открытом виде.
6. **Полная локальность и отсутствие телеметрии:**
   - База данных SQLite (`collection.db`), кэш и история изменений хранятся исключительно на локальном компьютере пользователя в системной папке данных приложения.
   - Проект не содержит сторонней аналитики, трекеров, пикселей отслеживания или скрытой отправки телеметрии.
7. **Неизменяемость исходных данных на уровне СУБД:**
   - Встроенный SQL-триггер `source_immutable` на уровне ядра базы данных SQLite блокирует любые попытки изменения или перезаписи исходных полей трека (`source`, `position`, `collection_id`), гарантируя целостность оригинальной выгрузки.
8. **Сетевая изоляция и раздельные прокси:**
   - Сессии VK и Spotify строго разделены (`src/main/platform/network.ts`). Плеер VK подключается напрямую к официальным CDN-узлам, предотвращая утечку сессионных заголовков во внешние прокси-каналы.
