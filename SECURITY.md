# Безопасность

VKSpot хранит коллекции, историю и настройки локально в SQLite. Телеметрии и скрытой передачи пользовательских данных нет. Приложение не запрашивает и не сохраняет пароли VK или Spotify.

- Веб-страницы сервисов изолированы от Node.js (`contextIsolation`, sandbox); renderer обращается к main только через типизированный `contextBridge`. IPC проверяет отправителя и валидирует данные.
- Скрипты интеграций читают отображённый DOM в изолированном мире; секреты и закрытые API VK не извлекаются. Профили VK и Spotify разделены. VK работает напрямую; прокси Spotify на сессию VK не распространяется.
- Spotify API использует OAuth 2.0 PKCE и callback только на `127.0.0.1:43823`. Токены хранятся через Electron `safeStorage`; если системное шифрование недоступно, открытый токен на диск не записывается.
- SQLite-триггер защищает исходные поля коллекции. Данные приложения находятся в системной папке пользователя; сессию VK можно очистить из интерфейса.
- Локальные аудиофайлы не загружаются в Spotify: их индексирует десктопный клиент Spotify на устройстве пользователя.

Сообщайте об уязвимости приватно сопровождающим проекта, указав версию, шаги воспроизведения и обезличенные данные. Не публикуйте секреты, личные архивы, токены или cookies в issue и тестовых фикстурах.
