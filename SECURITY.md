# Безопасность и приватность VKSpot

Проект разработан с приоритетом локальной изоляции, защиты данных пользователя и приватности:

- **Изоляция удалённого веб-контента:** страницы VK и Spotify загружаются в отдельных изолированных представлениях `WebContentsView` без доступа к Node.js (`nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`).
- **Изолированные миры выполнения:** скрипты поиска и выгрузки выполняются в изолированных мирах (`isolatedWorld`), считывая только видимый текст элементов DOM. Приложение не перехватывает и не сохраняет пароли, сессионные cookies или токены браузерных страниц.
- **Строгий IPC-контракт:** интерфейс взаимодействует с бэкендом через предварительно объявленный мост `preload`. Все входящие аргументы валидируются строгими Zod-схемами, а вызовы проверяются на принадлежность основному фрейму окна (`senderFrame === mainFrame`).
- **Авторизация по протоколу PKCE:** вход в Spotify Web API использует официальный OAuth 2.0 PKCE с криптографически стойким `code_verifier`, одноразовым `state` и локальным слушателем `127.0.0.1`.
- **Шифрование токенов в ОС:** токены доступа Spotify шифруются системным хранилищем операционной системы (`Electron safeStorage`). При недоступности системного хранилища токены не записываются на диск в открытом виде.
- **Полная локальность данных:** SQLite-база данных, история изменений и кэш хранятся исключительно на локальном компьютере пользователя. Проект не содержит телеметрии, трекеров или сторонних аналитических сервисов.
- **Неизменяемость исходных данных:** триггеры SQLite `source_immutable` гарантируют защиту исходных полей трека от случайного изменения или перезаписи.

## Сообщение об уязвимостях
